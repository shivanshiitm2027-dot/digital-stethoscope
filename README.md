# Digital Stethoscope — DSP Simulation

By Shivanshu Yadav | IIT Madras

Educational Python and Streamlit project with acoustic/electronic comparison, synthetic signals, filtering, gain control and audio playback.

## Run
    python -m pip install -r requirements.txt
    python -m streamlit run app.py

Software simulation; hardware implementation is planned.
